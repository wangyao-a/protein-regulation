# protein-regulation
Mechanisms of stability of metaphase spindle and associated proteins regulating microtubule flux

Wild-type.py is used to reproduce the simulation results for the wild-type spindle presented in Section 3.1 of the manuscript. 
BAL27862.py is used to reproduce the simulation results for the BAL27862-treated spindle presented in Section 3.3. 
Other simulation results reported in the manuscript can be reproduced using these two programs by modifying the corresponding model parameters as specified in the manuscript and Supporting Information.
